# Serene Spa — Static Website

This is a minimal, responsive static website for a spa. It includes:
- Homepage with hero
- About, Services, Gallery, Testimonials sections
- Booking/contact form (client-side demo)
- Responsive layout and accessible markup

How to use
1. Save the files (index.html, styles.css, script.js) in a folder.
2. Open index.html in a browser to preview locally.
3. To deploy: push to a GitHub repo and enable GitHub Pages (Settings → Pages → choose main branch or /docs). Or upload to any static host (Netlify, Vercel, Firebase Hosting, S3, etc).
